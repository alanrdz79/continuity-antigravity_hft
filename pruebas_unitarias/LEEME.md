# 🧪 Pruebas del Código (`pruebas_unitarias`)

**¿Para qué sirve esta carpeta?**
Contiene pequeños programas de prueba para validar que los conectores y las herramientas internas sigan funcionando correctamente tras una actualización.
Si algo falla, los programadores pueden venir aquí y ejecutar un script aislado (ej: probar si The-Odds-API sigue respondiendo) sin tener que arrancar todo el robot.
