# 🔌 Conectores (`conectores`)

**¿Para qué sirve esta carpeta?**
Agrupa todos los archivos que conectan el sistema CONTINUITY con el mundo exterior (APIs, plataformas de cuotas, mensajería y exchanges).

**Contenido Principal:**
- `matchbook_client.py`: Se conecta al Exchange de Matchbook para ejecutar apuestas de manera automática (Auto-Betting).
- `oddsharvester_client.py`: Controla navegadores invisibles (Headless) para raspar y obtener las mejores cuotas del mercado.
- `telegram_bot.py`: Envía las alertas directamente a tu celular a través del bot configurado en Telegram.
