# 🎛️ Orquestadores y Ejecutores (`orquestadores_principales`)

**¿Para qué sirve esta carpeta?**
Aquí se agrupan los programas principales que tú o el sistema ejecutan directamente. Son los "jefes" que coordinan al resto de los archivos. Al moverlos aquí, mantenemos la carpeta principal del proyecto completamente limpia y ordenada.

**Contenido:**
- `GALO.py`: El orquestador supremo 24/7. Ejecuta todo el flujo automatizado en la nube.
- `CONTINUITY.py`: La herramienta manual de línea de comandos para hacer predicciones bajo demanda.
- `CEREBELLIUM.py`: El motor ETL que limpia la base de datos de manera profunda.
- `GIGI.py`: El ejecutor contable, revisa qué apuestas cerraron y liquida el ROI.
- `diana.py`: El descargador masivo de datos (Soccerdata, Understat).
- `pacificokyj.py`: El panel interactivo de Streamlit.
- `PURGA.py`: Herramienta para limpieza profunda de las cachés y base de datos.
